# CafeCRM — Backend

REST API для CRM системы ресторана. Позволяет управлять столами, бронированиями, меню и заказами. Включает веб-панель для персонала и мобильное приложение для клиентов.

## Запуск

```bash
docker-compose up --build
```


## Доступ

|  | URL |
| :-- | :-- |
| API | `http://localhost:8080/api` |
| Документация | `http://localhost:8080/docs` |
